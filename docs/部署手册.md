# 部署手册｜二手集市 + AI 卖家助手

> 写给下届同学：把本项目从「本地能跑」搬到「公网可访问」的完整步骤。
> 本项目含 **Node.js 后端 + MySQL 数据库**，因此**不能用纯静态托管**（GitHub Pages / Gitee Pages 只能放前端，跑不了后端和数据库）。

## 一、先搞清楚：线上和本地差在哪

本地能跑 ≠ 线上能跑，差异无非四处，报错都围绕这四点排查：

| 差异点 | 本地 | 线上要注意 |
| --- | --- | --- |
| 环境变量/配置 | `.env` 写死 localhost | 数据库地址、端口、密钥走服务器环境变量，**别提交到仓库** |
| 数据库连接 | 本机 127.0.0.1 | 云数据库要放行服务器 IP，密码强度要够 |
| 依赖版本 | 你电脑的 Node | 服务器要装**相同大版本** Node（本项目用 Node 18+，开发用 v22） |
| 静态资源/跨域 | 前端 5500 后端 8080 | 线上建议用 Nginx 同源代理 `/api`，前端的 `BASE_URL` 改为相对路径 |

## 二、部署路线选择

| 路线 | 适合 | 成本 | 难度 |
| --- | --- | --- | --- |
| **A. 学生云服务器（推荐）** | 含后端的完整项目，想真正掌握部署 | 学生机约 10 元/月（阿里云/腾讯云学生认证） | 中（建议装宝塔面板） |

## 三、路线 A：学生云服务器部署（宝塔面板）

### 0. 你需要准备

- 一台云服务器（阿里云/腾讯云学生机， centos/ubuntu 均可），记下**公网 IP**
- 服务器装**宝塔面板**（官网一键安装命令，装完能打开 `http://公网IP:8888` 面板）

> ⏳ **待填**：我的服务器公网 IP = `______`（部署当天填入）

### 1. 装环境（宝塔面板里点点点）

在宝塔「软件商店」安装：
- **Nginx**（任意稳定版）——做 Web 服务和反向代理
- **MySQL 8.x**（或 5.7，与本地一致即可）
- **Node.js 版本管理器** → 装 **Node 18 或 20**（与本地大版本一致）

### 2. 上传代码

两种方式任选：
- **git 克隆（推荐）**：服务器上 `git clone https://gitee.com/lz208/vibe-lizhi.git`
- 或本地打包 `frontend/`、`backend/`、`database/` 三个目录，用宝塔「文件」上传后解压。

放到 `/www/wwwroot/flea-market/`（路径可自定）。

### 3. 初始化数据库

```bash
# 服务器上执行（密码用宝塔里设置的 MySQL root 密码）
mysql -u root -p < /www/wwwroot/flea-market/database/schema.sql
mysql -u root -p flea_market_ai < /www/wwwroot/flea-market/database/seed_data.sql
```

`schema.sql` 建库建表（含 page_views 访问统计表），`seed_data.sql` 写入演示数据。

### 4. 配置后端环境变量

在 `backend/` 下创建 `.env`（**不要提交到 git**）：

```ini
PORT=8080
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的服务器MySQL密码
DB_NAME=flea_market_ai
# 前端同源部署后，CORS 可放宽或删除该项
FRONTEND_ORIGIN=http://你的公网IP
```

安装依赖并启动：

```bash
cd /www/wwwroot/flea-market/backend
npm install --production
# 用 PM2 守护进程（宝塔 Node 管理器可一键装 PM2）
pm2 start src/server.js --name flea-market
pm2 save
pm2 startup   # 开机自启
```

验证：服务器上 `curl http://127.0.0.1:8080/api/health` 返回 `{"code":0,...,"data":"pong"}`。

### 5. 用 Nginx 同源托管前端 + 代理后端（关键）

把前端 `BASE_URL` 改成相对路径，让前端和后端**同域名**，彻底避开跨域：

改 [frontend/js/config.js](../frontend/js/config.js) 为：

```js
window.API_CONFIG = { BASE_URL: '/api' };
```

宝塔「网站」→「添加站点」→ 填公网 IP 或域名 → 网站目录指向 `frontend/`。然后在该站点「配置文件」里加反向代理：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

保存后重载 Nginx。此时：
- `http://公网IP/index.html` → 前端页面（Nginx 直接发静态文件）
- `http://公网IP/api/products` → 后端接口（Nginx 转发到 8080）

### 6. 放行端口

云服务器**安全组**要放行：`80`（HTTP）、`443`（HTTPS，做 C1 挑战用）、`8888`（宝塔面板，建议改默认端口+限定 IP）。
**不要**对外开放 `8080`（后端只给 Nginx 转发）和 `3306`（MySQL 只本机连）。

### 7. 验收

手机（用流量，不是校园网）打开 `http://公网IP/index.html`：

- [ ] 点「统计看板」能看到图表
- [ ] 翻页、搜索、分类正常

## 四、C1 挑战：HTTPS + 自定义二级域名（可选）

1. 买一个域名（或用免费域名），在域名服务商处添加 **A 记录**：`flea.你的域名.com` → 服务器公网 IP
2. 宝塔该站点 → 「SSL」→ 申请 **Let's Encrypt 免费证书** → 开启「强制 HTTPS」
3. Nginx 站点「域名管理」加上 `flea.你的域名.com`
4. 验收：地址栏出现小锁，`https://flea.你的域名.com` 可访问

## 五、常见报错速查（本地好线上坏）

| 现象 | 大概率原因 | 排查 |
| --- | --- | --- |
| 线上白屏 | 静态资源 404 / BASE_URL 没改相对路径 / 跨域 | F12 看 Console 红字，整段喂回 AI |
| 接口 502 | 后端没起来 / pm2 挂了 | 服务器上 `pm2 logs flea-market`、`curl 127.0.0.1:8080/api/health` |
| 接口 500 / 连不上数据库 | `.env` 密码错 / MySQL 没放行 | 核对 `.env`；确认 MySQL `bind-address` 和防火墙 |
| 图表不显示 | CDN（jsdelivr）被墙 | 把 echarts.min.js 下载到本地 `frontend/js/lib/` 引用 |
| 改了代码不生效 | 浏览器缓存 / Nginx 缓存 | Ctrl+F5 强刷；`pm2 restart` |

## 附录：路线 B（免费托管，备选）

- **前端**：Vercel / Netlify 直接拖 `frontend/` 目录（纯静态，免费）
- **后端**：Render 免费 Web Service，连 Git 仓库自动部署，选 Node 环境，启动命令 `node backend/src/server.js`
- **数据库**：免费 MySQL（如 Railway / Aiven 免费档），把 `DB_HOST` 等填到 Render 的环境变量里
- 注意：免费档会**休眠**（15 分钟无请求后首次访问慢），数据库有容量/连接数限制，适合演示不适合长期使用。
