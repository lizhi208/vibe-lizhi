# 数据字典｜flea_market_ai

> 依据 `database/schema.sql` 生成（可通过 MySQL MCP 让 AI 直连库重新生成核对）。
> 字符集 utf8mb4；5 张业务表 + 1 张访问统计表。

## 1. users 用户表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK，自增 | 用户 ID |
| username | VARCHAR(50) | NOT NULL，UNIQUE(uk_username) | 登录名 |
| password_hash | VARCHAR(100) | NOT NULL，默认 '' | 密码哈希（骨架期为空） |
| nickname | VARCHAR(50) | NOT NULL，默认 '' | 昵称 |
| role | ENUM('SELLER','BUYER') | NOT NULL，默认 'BUYER' | 角色 |
| created_at | DATETIME | NOT NULL，默认 CURRENT_TIMESTAMP | 创建时间 |

初始数据：id=1 演示卖家（SELLER）、id=2 演示买家（BUYER）。

## 2. categories 商品分类表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK，自增 | 分类 ID |
| name | VARCHAR(50) | NOT NULL，UNIQUE(uk_name) | 分类名称 |
| sort_order | INT | NOT NULL，默认 0 | 展示排序（升序） |

初始数据：1 数码电子 / 2 图书教材 / 3 生活用品 / 4 运动户外 / 5 服饰鞋包。

## 3. products 商品表

状态机：`ON_SALE`（在售）→ `LOCKED`（已锁定）→ `SOLD`（已成交）。

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK，自增 | 商品 ID |
| seller_id | BIGINT UNSIGNED | NOT NULL，FK→users.id | 发布者 |
| category_id | BIGINT UNSIGNED | NOT NULL，FK→categories.id | 分类 |
| title | VARCHAR(100) | NOT NULL | 标题（卖家确认后的最终稿） |
| description | TEXT | NULL | 详情描述（卖家确认后的最终稿） |
| image_url | VARCHAR(500) | NOT NULL，默认 '' | 物品图片地址 |
| price | DECIMAL(10,2) | NOT NULL | 最终售价（卖家可覆盖 AI 参考价） |
| reference_price | DECIMAL(10,2) | NULL | AI 给出的参考报价（仅参考） |
| status | ENUM('ON_SALE','LOCKED','SOLD') | NOT NULL，默认 'ON_SALE' | 状态机 |
| created_at | DATETIME | NOT NULL，默认 CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL，ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

索引：idx_seller(seller_id)、idx_category_status(category_id,status)、idx_status_created(status,created_at)、ft_title_desc(title,description) 全文索引（MySQL 8 + ngram，不可用时退回 LIKE）。

## 4. orders 订单表（仅状态流转，无支付物流）

状态机：`LOCKED`（已锁定）→ `DEAL`（已成交）/ `CANCELLED`（已取消）。

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK，自增 | 订单 ID |
| product_id | BIGINT UNSIGNED | NOT NULL，FK→products.id | 商品 |
| buyer_id | BIGINT UNSIGNED | NOT NULL，FK→users.id | 买家 |
| status | ENUM('LOCKED','DEAL','CANCELLED') | NOT NULL，默认 'LOCKED' | 状态机 |
| created_at | DATETIME | NOT NULL，默认 CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL，ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

索引：idx_product(product_id)、idx_buyer(buyer_id)。

## 5. ai_generation_logs AI 生成记录表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK，自增 | 记录 ID |
| product_id | BIGINT UNSIGNED | NULL | 关联商品（生成草稿时可能尚未发布） |
| type | ENUM('DRAFT','ANSWER') | NOT NULL，默认 'DRAFT' | DRAFT 草稿 / ANSWER 应答（P1） |
| input_ref | VARCHAR(500) | NOT NULL，默认 '' | 输入摘要/图片引用 |
| output_text | MEDIUMTEXT | NULL | AI 原始输出 |
| created_at | DATETIME | NOT NULL，默认 CURRENT_TIMESTAMP | 创建时间 |

索引：idx_product(product_id)。用途：排查「AI 输出不稳定」问题；C1 用法统计的数据源。

## 6. page_views 页面访问统计表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| path | VARCHAR(200) | PK | 页面路径 |
| views | BIGINT UNSIGNED | NOT NULL，默认 0 | 访问次数（同 path 累加） |
| updated_at | DATETIME | NOT NULL，ON UPDATE CURRENT_TIMESTAMP | 最近访问时间 |
