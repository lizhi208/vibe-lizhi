# 演示脚本｜第 9、10 天就靠它

## 收工三行（第 7 天填写）

- **点哪里**：发布页（publish.html）→ 选一张物品照片 → 点「一键生成标题 / 描述 / 参考价」
- **AI 生成什么**：商品标题、80-200 字详情描述、二手参考价（回填表单，卖家可改后确认发布）
- **断网时显示什么**：「AI 服务暂不可达，请检查网络；也可以直接手动填写后发布」（不白屏，手动发布路径不断）

## 演示动线（约 90 秒）

1. 首页浏览/搜索 → 进入一个商品详情（证明基本闭环可用）
2. 进发布页，上传照片，点 AI 生成 → 表单自动回填草稿
3. 改一两个字 + 改价 → 确认发布 → 回首页看到新商品
4. **断网演练**（评委前必演）：拔网线/关 Wi-Fi，再点一次 AI 生成 → 优雅提示「AI 服务暂不可达」，手动填写仍可发布
5. 讲一句账：单次调用约 0.003 元，月度成本表见 docs/AI成本估算.md；Key 只在后端，F12 看不到
