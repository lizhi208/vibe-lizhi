## 1. 项目背景与概述

普通个人闲置卖家在二手平台发布商品时，需要手动完成**写标题、写描述、估价格、回复买家咨询**等工作，耗时费力，上架门槛高，导致大量闲置物品迟迟不能发布流通。

本产品是一个内置 AI 卖家助手的二手集市：卖家**拍照上传物品照片**，即可借助第三方大模型能力自动完成发布准备（文案生成、参考报价、买家咨询应答），降低二手物品上架门槛、提升闲置发布效率。

## 2. 目标用户与痛点

### 2.1 目标用户

- **主要用户：普通个人闲置卖家**——偶尔处理家中闲置物品、非职业商家。
- 次要使用者：浏览并购买闲置物品的**个人买家**（原型中买家能力从简）。

### 2.2 核心痛点

1. 写商品标题、详情文案麻烦，不会描述物品卖点。
2. 不了解市场行情，二手定价凭感觉、容易定高或定低。
3. 买家重复提问（成色、能否便宜、怎么交易等），逐条回复压力大。

> 用户真实性判断：普通人处理闲置普遍嫌写文案、估价麻烦，是现实中真实存在的痛点。

## 3. 产品目标与价值

| 目标 | 衡量方向（演示期定性指标） |
| --- | --- |
| 降低上架门槛 | 卖家上传 1 张照片即可得到可编辑的完整发布草稿 |
| 提升发布效率 | 从"拍照"到"可发布"由数分钟缩短到一键生成、二次确认 |
| 辅助合理定价 | 每件商品给出基于同类商品的参考报价 |
| 减轻沟通负担 | 买家高频问题可由 AI 自动应答 |

## 4. 项目范围

### 4.1 本期交付（最小可行闭环）

**商品发布（图 + 文）→ 列表 / 搜索 / 分类 → 详情页 → 下单锁定。**

具体包含：

1. AI 生成商品标题与详情文案（上传照片触发）。
2. AI 给出二手参考报价。
3. 商品列表、搜索、分类浏览。
4. 商品详情页。
5. 下单锁定与商品状态流转（标记成交）。

### 4.2 明确不做（本期边界）

- ❌ 在线支付。
- ❌ 物流配送。
- ❌ 成交仅通过修改商品状态标记完成，不涉及真实交易资金流。

### 4.3 进阶功能（不纳入第一版，留待后续迭代）

- AI 应答买家常见咨询（**优先级最低，时间不够时第一个砍掉**，砍掉后"文案 + 估价"仍可跑通最小闭环）。
- 以图搜同类商品。
- AI 砍价 agent。

## 5. 角色定义

| 角色 | 说明 | 核心诉求 |
| --- | --- | --- |
| 卖家 | 发布并管理自己闲置物品的个人用户 | 快速上架、合理定价、减少重复沟通 |
| 买家 | 浏览、搜索商品并发起购买的个人用户 | 找到商品、了解信息、锁定商品 |
| AI 卖家助手 | 第三方大模型 API 能力的产品化封装（系统角色） | 产出文案/报价/咨询回复的**草稿建议**，不自动决策 |

## 6. 功能需求

优先级定义：**P0 = 最小闭环必需**；**P1 = 增强体验，可裁剪**。

### 6.1 AI 生成商品标题与详情文案（P0）

- **功能描述**：卖家上传物品照片后，AI 自动生成商品标题与描述文案。
- **输入**：1 张（或多张）物品照片。
- **处理**：前端上传图片 → 后端调用第三方大模型 API（多模态/图像理解）→ 返回标题与描述。
- **输出**：商品标题（简短）、商品详情文案（结构化描述）。
- **关键规则**：
  - AI 输出**仅为草稿建议**，必须进入可编辑状态，由卖家二次修改、确认后才能发布。
  - **禁止 AI 结果直接自动提交上架。**
- **验收标准**：
  1. 上传照片后可一键生成标题与描述，结果展示在发布草稿页。
  2. 标题、描述均可由卖家手动编辑。
  3. 卖家点击确认后商品才正式发布。

### 6.2 AI 二手参考报价（P0）

- **功能描述**：识别物品信息后，给出历史同类商品的二手参考定价。
- **输入**：物品照片（及 AI 识别出的物品信息，必要时卖家补充的品类/成色）。
- **处理**：调用 AI / 行情数据，对同类历史商品价格进行参考分析。
- **输出**：参考价格（或价格区间），并以"参考"性质呈现。
- **关键规则**：
  - 报价为**建议值**，最终售价由卖家确认或修改。
  - 需明确标注"AI 参考价"，避免误导为官方定价。
- **验收标准**：
  1. 生成文案的同时（或卖家触发后）给出参考报价。
  2. 价格字段可被卖家覆盖修改。

### 6.3 商品发布（P0）

- **功能描述**：卖家以"图片 + 文字 + 价格"形式发布商品。
- **输入**：商品图片、标题、详情、价格、分类。
- **处理**：后端进行商品数据的增删改查（CRUD）与状态管理，写入数据库。
- **输出**：发布成功后商品出现在商品列表，状态为"在售"。
- **验收标准**：
  1. 必填项（图片、标题、价格）缺失时不可发布并有提示。
  2. 发布后可在列表与详情页查到该商品。

### 6.4 商品列表 / 搜索 / 分类（P0）

- **功能描述**：买家/卖家浏览全部在售商品，支持按关键词搜索与按分类筛选。
- **输入**：搜索关键词、分类条件。
- **输出**：商品卡片列表（图片、标题、价格、状态）。
- **验收标准**：
  1. 默认按时间或默认排序展示在售商品。
  2. 关键词可命中商品标题/描述；可按分类过滤。
  3. 已成交/已锁定商品有明确状态标识或从在售列表中排除（演示口径二选一，需在设计时确定）。

### 6.5 商品详情页（P0）

- **功能描述**：展示商品完整信息：图片、标题、详情描述、价格、分类、发布信息与交易状态。
- **输出**：商品详情视图，并提供"下单/我想要"入口。
- **验收标准**：从列表点击任一商品可进入对应详情，信息与发布内容一致。

### 6.6 下单锁定与成交状态流转（P0）

- **功能描述**：买家在详情页发起下单，商品被锁定；最终仅通过**修改商品状态**标记成交。
- **状态流转（建议）**：`在售 → 已锁定（有人下单）→ 已成交`。
- **关键规则**：
  - 不做支付、不做物流。
  - 锁定后其他买家不能再次下单（具体是否允许取消锁定由设计细化）。
- **验收标准**：
  1. 下单操作后商品状态即时变更并在列表/详情可见。
  2. 已成交商品不可再次下单。

### 6.7 AI 应答买家常见咨询（P1，可裁剪）

- **功能描述**：针对买家高频问题（成色、配件、交易方式、能否议价等），AI 基于商品信息自动回复，减轻卖家回复压力。
- **输入**：买家提问、对应商品信息。
- **输出**：AI 回复草稿或自动答复。
- **关键规则**：与 6.1/6.2 同口径——AI 答复为辅助性质，涉及价格、承诺类内容时建议经卖家确认（具体自动/手动程度在设计阶段确定）。
- **裁剪说明**：若工期不足，**优先砍掉本功能**；保留"文案生成 + 参考报价"仍构成完整最小闭环。

## 7. 核心用户流程

### 7.1 卖家发布流程（演示主路径）

```
拍照/上传物品照片
      │
      ▼
一键调用 AI ──► 生成标题 + 详情文案 + 参考报价
      │
      ▼
打开发布草稿页（第一眼演示重点）
      │
      ▼
卖家二次编辑/确认（可改文案、改价格）
      │
      ▼
确认发布 ──► 商品上架（在售）
```

### 7.2 买家购买流程

```
浏览列表 / 搜索 / 分类筛选
      │
      ▼
进入商品详情页
      │
      ▼
发起下单 ──► 商品锁定（在售 → 已锁定）
      │
      ▼
标记成交（仅状态变更，无支付/物流）
```

## 8. 风险与对策

| 风险 | 等级 | 影响 | 对策 |
| --- | --- | --- | --- |
| **AI 输出文案、估价质量不稳定，出现错误信息**（最大风险） | 高 | 误导买卖双方、产生纠纷 | AI 输出**一律作为草稿建议**，全部交由卖家二次编辑确认后再发布/采用，**不做任何自动提交**；界面明确标注"AI 生成，仅供参考" |
| 第三方大模型 API 不可用或超时 | 中 | 无法生成文案/报价，阻塞发布 | 支持失败重试；允许卖家跳过 AI、手动填写后正常发布，保证发布闭环可用 |
| API 调用成本/频次受限 | 中 | 演示或使用受限 | 仅在发布准备等关键节点调用，不做无意义高频调用 |
| 图片内容无法识别 | 中 | 生成结果偏差 | 允许卖家手动修正物品信息后重新生成或直接手填 |

## 9. 技术基础与约束

依据现有学习基础，技术方案以"可完成、可演示"为原则：

1. **后端 + 数据库**：商品 CRUD、列表、详情、状态流转——使用课程已掌握的后端与数据库知识实现。
2. **前端**：图片上传、页面交互与展示、接口调用——使用已学 Web 前端技术。
3. **AI 能力**：**只调用第三方大模型 API，不自研、不训练大模型**，最大限度降低开发量。
4. 部署目标：支持课堂展示与 Gitee Pages 等静态/轻量部署方式（后端 API 部署方式在设计阶段明确）。

## 10. 演示脚本（验收第一眼）

> **演示第一眼看什么**：上传一张二手物品照片 → 一键 AI 生成标题、描述与参考价格 → 展示**发布草稿页面**。

建议演示顺序：

1. 上传物品照片，一键生成文案 + 参考价（核心亮点）。
2. 卖家在草稿页修改并确认发布。
3. 进入商品列表 → 搜索/分类 → 打开详情页。
4. 买家下单锁定 → 标记成交，展示状态流转。
5. （若保留 P1）展示一条 AI 应答买家咨询的示例。

## 11. 验收标准（最小闭环完成定义）

- [ ] 能上传物品图片并由 AI 生成可编辑的标题与详情文案。
- [ ] 能给出 AI 参考报价，且卖家可修改。
- [ ] AI 内容必须经卖家确认后才发布，无任何自动上架路径。
- [ ] 商品可正常发布，并在列表/搜索/分类/详情中正确呈现。
- [ ] 详情页可下单锁定，商品状态可流转至成交；成交后不可重复下单。
- [ ] 全程不涉及支付与物流。
- [ ] AI 服务异常时，卖家仍可手动发布商品，闭环不中断。
- [ ] 主演示路径可在课堂环境稳定跑通。
